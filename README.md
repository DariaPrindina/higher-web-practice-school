# На страже Волшебной школы
Консольное приложение с ролевой моделью доступа (RBAC + условия)

## Описание

Приложение реализует систему авторизации и контроля доступа для Волшебной школы.  
Разные роли (ученик, родитель, учитель, охранник, Сова, Кристофер Робин) имеют разные права на вход в локации и просмотр/редактирование журнала оценок.

Основные ограничения:
- Журнал можно смотреть **только находясь в школе** (`enter school`)
- Ученик и родитель могут смотреть журнал **только в присутствии учителя**
- Родитель видит **только оценки своего ребёнка**
- В класс можно войти **только при присутствии учителя в классе** (условное разрешение)
- Учитель может видеть и редактировать весь журнал
- Охранник может только входить/выходить из школы
- Сова (Chief) имеет доступ в свой кабинет, куда другим нельзя
- Кристофер Робин (Admin) — суперпользователь

## Архитектура (кратко)

- **Роли** → `Role` (абстрактный `AbstractRole` + конкретные классы)
- **Разрешения** → `Permission`
    - `SimplePermission` — безусловное
    - `ConditionalPermission` — с условием (`Condition`)
- **Условия** → `Condition`
    - `TeacherPresentCondition` — проверяет наличие учителя в локации / школе
- **Состояние школы** → `SecureStateImpl`
    - `occupants: Map<Location, Set<User>>` — кто именно в какой локации
    - `history` — лог действий
    - `journal` — оценки
- **Авторизация** → `AuthorizationService.isAllowed(...)`
- **Аутентификация** → `AuthService` (хранит пользователей из `SecureDatabase`)
